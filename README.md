# loongwz 的个人主页

网站地址：<https://loongwz.github.io/>

这是一个简洁的中文个人网站，使用 GitHub Pages 发布。页面内容、样式都在 `index.html` 中，无需安装依赖。

## 修改内容

1. 在 GitHub 仓库中打开 `index.html`。
2. 点击铅笔图标进行编辑，修改姓名、介绍或链接。
3. 提交修改，等待 GitHub Pages 自动更新。

## 发布设置

仓库名称为 `loongwz.github.io`，在 **Settings → Pages** 中使用 **Deploy from a branch**，来源为 `main` 分支的根目录 `/`。

`.nojekyll` 告诉 GitHub Pages 直接发布静态文件。
